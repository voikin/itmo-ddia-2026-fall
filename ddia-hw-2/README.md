# HW2: тесты

Нужны Rust 1.85+ и Cargo. Команды выполняются из корня репозитория.

Все тесты:

```sh
./test.sh
```

Из папки `ddia-hw-2`: `cargo test --locked`.

## Подготовительная часть: default

```sh
./test.sh --test default
```

- Успешный ответ сохраняет статус и тело; выполняется один подзапрос.
- Ошибка 4xx возвращается без повтора.
- Ошибка 5xx возвращается без повтора.
- Зависший подзапрос отменяется по таймауту.
- Ответ с задержкой принимается, если укладывается в бюджет.

## Часть 1: retries

```sh
./test.sh --test retries
```

- После 4xx, 5xx и таймаута запрос повторяется до успеха.
- Повторы прекращаются при исчерпании бюджета 4xx.
- Повторы прекращаются при исчерпании бюджета 5xx.
- Повторы прекращаются при исчерпании бюджета таймаутов.
- Общий бюджет времени ограничивает следующую попытку.

## Часть 2: exponential backoff

```sh
./test.sh --test backoff
```

- Задержки после 5xx удваиваются до успешного ответа.
- Таймауты и 5xx используют общую последовательность задержек.
- После 4xx повтор немедленный, следующая задержка не меняется.
- Задержка расходует общий бюджет и сокращает время следующей попытки.
- После исчерпания бюджета ошибок дополнительной задержки нет.

## Часть 3: round-robin

```sh
./test.sh --test round_robin
```

- Успех первого сервера прекращает обход.
- Серверы обходятся по кругу после ошибок и таймаута.
- Бюджеты ошибок общие для всех серверов.
- Общее число попыток ограничено независимо от сервера.
- Общий таймаут действует на весь обход серверов.

## Часть 4: hedging

```sh
./test.sh --test hedging
```

- Быстрый успех первого сервера не запускает остальные.
- После задержки остальные серверы стартуют одновременно; побеждает самый быстрый успешный ответ.
- Ошибка одного дополнительного запроса не мешает дождаться успеха другого.
- Если все серверы ответили ошибками, клиент завершается по общему таймауту.
- Общий таймаут отменяет все зависшие подзапросы.

## Часть 5: circuit breaking

```sh
./test.sh --test circuit_breaker
```

- Восстановившийся сервер обслуживает запросы, пока другой отключён.
- Ожидание ближайшего восстановления не расходует число попыток.
- Ошибки 4xx, 5xx и таймауты отключают сервер до окончания паузы.
- Разные ошибки суммируются до порога; после восстановления счётчик сбрасывается.
- Ожидание восстановления ограничено общим бюджетом времени.
